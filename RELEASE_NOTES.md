# Goblins of the Ashborn Isles 0.5.2 - Shatterfin Tidemothers

For Europa Universalis V 1.3.11 (Pavia). Close EU5 and start a NEW 1337 campaign after installing.

- Shatterfin gains Tidemother Monarchy and maternal dynastic seniority, led by Jaima Shatterfin, the Mare-Mother.
- Goblin naming pools and authored royal families, courts and cabinets across all five Ashborn cultures; Cindermaw's king is the Stone Fletcher.
- Includes the 36-location volcanic terrain update, connected sea routes, native goblin infantry and culture-based portrait pass.
- Preserves corrected native-compatible portrait textures and installer checks for stale bundles, version mismatches and file checksums.

Download Goblins_Ashborn_Isles_0.5.2.zip, extract it and run Install-Goblins.cmd. The installer reconstructs terrain using your matching EU5 installation and backs up an existing local mod.

Validation: static build checks passed. Installer preparation verified the archive checksum, development file checksums and reconstructed terrain hashes. In-game succession, rendering and gameplay acceptance remain pending; this is a prerelease.
